# Cronômetro de Estudos

Cronômetro de blocos de foco + pausas, feito para ficar aberto na tela do tablet ou do celular.

- Blocos de foco (30, 45, 60, 90 min ou qualquer valor) e pausas (5, 10, 15 min ou qualquer valor)
- Quantidade de blocos ajustável; mostra a que horas a sessão termina
- Som suave ao trocar de fase e **despertador** no final da sessão (toca até você parar)
- Mantém a tela ligada enquanto roda, botão de tela cheia, vibração no Android
- Lembra os ajustes e continua de onde parou se a página recarregar
- Conta quanto tempo de foco você fez hoje

Atalhos no teclado: `Espaço` inicia/pausa, `N` pula a fase, `R` reinicia.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `cronometro-estudos`).
2. Clique em **Add file → Upload files** e envie os 4 arquivos desta pasta (`index.html`, `manifest.webmanifest`, `icon.svg`, `README.md`). Clique em **Commit changes**.
3. Vá em **Settings → Pages**. Em *Branch*, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Em 1–2 minutos o link fica pronto: `https://SEU-USUARIO.github.io/cronometro-estudos/`

## Usar no tablet / celular

- Abra o link no Chrome e toque em **⋮ → Adicionar à tela inicial**. Ele abre como app, sem a barra do navegador.
- Toque no ▶ uma vez para começar: é esse toque que libera o som do alarme no navegador.
- Deixe o volume de mídia ligado. No iPhone, a chave de silencioso também corta o som.
- Deixe a página aberta na tela; se o aparelho bloquear a tela ou você trocar de app, o navegador pode segurar o som até você voltar.
